# Login de un solo usuario — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Proteger toda la app (páginas, API, WebSocket y vídeos) con un login de un solo usuario (usuario y contraseña, sesión de 12 h) y una página de login con el diseño B.

**Architecture:** `backend/app/auth.py` reúne las piezas en Python puro, sin dependencias: hash `scrypt`, token firmado con HMAC, limitador de intentos, helpers de proxy y el comando `crear-credenciales`. Un middleware ASGI (`auth_middleware.py`) exige la cookie `el_session` en todo salvo una lista blanca. Las rutas `/api/auth/{login,logout,status}` emiten y borran la cookie. La página `login.html` es estática y reutiliza `styles.css`, `i18n.js` e `icons.js`.

**Tech Stack:** FastAPI 0.141 / Starlette 1.6, pydantic-settings 2.15, biblioteca estándar (`hashlib.scrypt`, `hmac`, `secrets`), JS y CSS vanilla, pytest.

**Spec:** `docs/superpowers/specs/2026-09-29-login-design.md`

## Global Constraints

- **Sin dependencias nuevas.** `backend/app/auth.py` solo usa la biblioteca estándar.
- Nombre de la cookie: `el_session`. Atributos: `HttpOnly`, `SameSite=Strict`, `Path=/`, `Max-Age=43200` (12 h, derivado de `auth_session_hours`), y `Secure` solo cuando la conexión es HTTPS.
- Formato del hash: `scrypt:16384:8:1:<sal_b64url>:<hash_b64url>`, separado por `:` y sin ningún `$`.
- Límite de intentos: 5 fallos en 15 min → bloqueo de 15 min por IP. Un login correcto reinicia el contador de esa IP.
- `X-Real-IP` y `X-Forwarded-Proto` solo se creen si la conexión viene de `127.0.0.1` o `::1`.
- Rutas públicas (exactas): `/login.html`, `/css/styles.css`, `/js/login.js`, `/js/i18n.js`, `/js/icons.js`, `/api/auth/login`, `/api/auth/status`, `/api/health`, más el prefijo `/i18n/`. Una ruta con un segmento `..` **nunca** es pública.
- Sin sesión: páginas → `302` a `/login.html?next=<ruta codificada>`; `/api/*` → `401 {"detail": "not_authenticated"}`; WebSocket → se acepta y se cierra con el código `4401`.
- `next` solo acepta rutas que empiecen por `/` y no por `//` ni por `/\`; si no, `/`.
- Credenciales: contraseña de al menos 8 caracteres; usuario no vacío y sin espacios.
- `AUTH_ENABLED` vale `true` por defecto. En el `.env` local (no versionado): `AUTH_ENABLED=false`.
- Textos visibles en ES y EN, con claves `login.*` y `auth.logout`, en `frontend/i18n/es.json` y `en.json`.

# backend/app/auth.py
"""
EmotionLens — single-user login primitives.

Standard library only: the CLI at the bottom runs on a fresh VPS during
deploy/setup_vps.sh, and none of this needs FastAPI. The middleware
(auth_middleware.py) and the /api/auth router build on these pieces.

Usage:
    python -m backend.app.auth crear-credenciales [--env RUTA]
"""
import argparse
import base64
import binascii
import getpass
import hashlib
import hmac
import math
import secrets
import sys
import time
from collections import defaultdict, deque
from pathlib import Path

COOKIE_NAME = "el_session"

SCRYPT_N, SCRYPT_R, SCRYPT_P = 2 ** 14, 8, 1
MIN_PASSWORD_LENGTH = 8

MAX_FAILURES = 5
WINDOW_SECONDS = 15 * 60
LOCKOUT_SECONDS = 15 * 60

# Nginx on the same host; only then are X-Real-IP / X-Forwarded-Proto trusted.
TRUSTED_PROXIES = frozenset({"127.0.0.1", "::1"})


def _b64e(data: bytes) -> str:
    return base64.urlsafe_b64encode(data).decode("ascii").rstrip("=")


def _b64d(text: str) -> bytes:
    return base64.urlsafe_b64decode(text + "=" * (-len(text) % 4))


# ── Password hashing ─────────────────────────────────────────────────

def hash_password(password: str, *, salt: bytes | None = None) -> str:
    """scrypt, stored as scrypt:n:r:p:salt:hash. ':' rather than '$' so the
    value survives .env parsing untouched."""
    salt = salt or secrets.token_bytes(16)
    digest = hashlib.scrypt(password.encode("utf-8"), salt=salt,
                            n=SCRYPT_N, r=SCRYPT_R, p=SCRYPT_P, dklen=32)
    return f"scrypt:{SCRYPT_N}:{SCRYPT_R}:{SCRYPT_P}:{_b64e(salt)}:{_b64e(digest)}"


def verify_password(password: str, stored: str) -> bool:
    try:
        scheme, n, r, p, salt, digest = stored.split(":")
        if scheme != "scrypt":
            return False
        expected = _b64d(digest)
        actual = hashlib.scrypt(password.encode("utf-8"), salt=_b64d(salt),
                                n=int(n), r=int(r), p=int(p), dklen=len(expected))
    except (ValueError, TypeError, binascii.Error):
        return False
    return hmac.compare_digest(actual, expected)


# ── Session token ────────────────────────────────────────────────────

def _signing_key(secret_key: str, password_hash: str) -> bytes:
    # Mixing in the password hash means a password change logs out every
    # open session without any server-side session store.
    return hashlib.sha256(f"{secret_key}\x00{password_hash}".encode("utf-8")).digest()


def _sign(payload: str, secret_key: str, password_hash: str) -> str:
    mac = hmac.new(_signing_key(secret_key, password_hash), payload.encode("ascii"), hashlib.sha256)
    return _b64e(mac.digest())


def make_token(username: str, *, secret_key: str, password_hash: str,
               ttl_seconds: int, now: float | None = None) -> str:
    now = time.time() if now is None else now
    payload = _b64e(f"{username}|{int(now + ttl_seconds)}".encode("utf-8"))
    return f"{payload}.{_sign(payload, secret_key, password_hash)}"


def token_is_valid(token: str, *, username: str, secret_key: str, password_hash: str,
                   now: float | None = None) -> bool:
    now = time.time() if now is None else now
    try:
        payload, sig = token.split(".")
        if not hmac.compare_digest(sig.encode("ascii"),
                                   _sign(payload, secret_key, password_hash).encode("ascii")):
            return False
        user, expires = _b64d(payload).decode("utf-8").rsplit("|", 1)
        return (hmac.compare_digest(user.encode("utf-8"), username.encode("utf-8"))
                and now < int(expires))
    except (ValueError, UnicodeError, binascii.Error):
        return False


# ── Login attempt limiter ────────────────────────────────────────────

class LoginRateLimiter:
    """In memory, per IP: MAX_FAILURES within WINDOW_SECONDS locks that IP
    out for LOCKOUT_SECONDS. One process, one user: a restart forgetting the
    counters is acceptable."""

    def __init__(self, clock=time.monotonic):
        self._clock = clock
        self._failures: dict[str, deque] = defaultdict(deque)
        self._locked_until: dict[str, float] = {}

    def retry_after(self, ip: str) -> int:
        until = self._locked_until.get(ip)
        if until is None:
            return 0
        remaining = until - self._clock()
        if remaining <= 0:
            del self._locked_until[ip]
            return 0
        return int(math.ceil(remaining))

    def record_failure(self, ip: str) -> None:
        now = self._clock()
        attempts = self._failures[ip]
        attempts.append(now)
        while attempts and now - attempts[0] > WINDOW_SECONDS:
            attempts.popleft()
        if len(attempts) >= MAX_FAILURES:
            self._locked_until[ip] = now + LOCKOUT_SECONDS
            attempts.clear()

    def record_success(self, ip: str) -> None:
        self._failures.pop(ip, None)
        self._locked_until.pop(ip, None)


# ── Request context behind Nginx ─────────────────────────────────────

def header(scope: dict, name: bytes) -> str | None:
    for key, value in scope.get("headers", []):
        if key == name:
            return value.decode("latin-1")
    return None


def _peer(scope: dict) -> str:
    client = scope.get("client")
    return client[0] if client else ""


def client_ip(scope: dict) -> str:
    peer = _peer(scope)
    if peer in TRUSTED_PROXIES:
        real = header(scope, b"x-real-ip")
        if real:
            return real.strip()
    return peer or "unknown"


def is_https(scope: dict) -> bool:
    if _peer(scope) in TRUSTED_PROXIES:
        proto = header(scope, b"x-forwarded-proto")
        if proto:
            return proto.strip().lower() == "https"
    return scope.get("scheme") in ("https", "wss")


# ── Credentials in .env ──────────────────────────────────────────────

def credential_lines(username: str, password: str, *, secret_key: str | None = None) -> dict[str, str]:
    username = username.strip()
    if not username or any(ch.isspace() for ch in username):
        raise ValueError("El usuario no puede estar vacío ni tener espacios")
    if len(password) < MIN_PASSWORD_LENGTH:
        raise ValueError(f"La contraseña debe tener al menos {MIN_PASSWORD_LENGTH} caracteres")
    return {
        "AUTH_ENABLED": "true",
        "AUTH_USERNAME": username,
        "AUTH_PASSWORD_HASH": hash_password(password),
        "AUTH_SECRET_KEY": secret_key or secrets.token_urlsafe(48),
    }


def upsert_env(path: Path, values: dict[str, str]) -> None:
    """Replace those keys in a .env file (or append them), keeping every
    other line as it was."""
    path = Path(path)
    lines = path.read_text(encoding="utf-8").splitlines() if path.exists() else []
    kept = [line for line in lines if line.split("=", 1)[0].strip() not in values]
    kept += [f"{key}={value}" for key, value in values.items()]
    path.write_text("\n".join(kept) + "\n", encoding="utf-8")


def missing_auth_settings(s) -> list[str]:
    if not s.auth_enabled:
        return []
    return [name.upper() for name in ("auth_username", "auth_password_hash", "auth_secret_key")
            if not getattr(s, name)]


# ── CLI ──────────────────────────────────────────────────────────────

def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="python -m backend.app.auth")
    sub = parser.add_subparsers(dest="command", required=True)
    create = sub.add_parser("crear-credenciales",
                            help="Pide usuario y contraseña y genera las variables AUTH_* del .env")
    create.add_argument("--env", type=Path, default=None,
                        help="Escribe las variables en este archivo en vez de imprimirlas")
    args = parser.parse_args(argv)

    username = input("Usuario: ")
    password = getpass.getpass("Contraseña: ")
    if password != getpass.getpass("Repite la contraseña: "):
        print("[ERROR] Las contraseñas no coinciden", file=sys.stderr)
        return 1
    try:
        values = credential_lines(username, password)
    except ValueError as exc:
        print(f"[ERROR] {exc}", file=sys.stderr)
        return 1

    if args.env:
        upsert_env(args.env, values)
        print(f"[OK] Credenciales escritas en {args.env}. Reinicia el servicio para aplicarlas.")
    else:
        print("\n".join(f"{key}={value}" for key, value in values.items()))
    return 0


if __name__ == "__main__":
    sys.exit(main())

```python
# backend/app/routers/auth.py
"""
EmotionLens — /api/auth: single-user login, logout and status.

The password check always runs, even when the username is wrong, and both
failures answer the same, so the response gives no hint about which half
was right. See backend/app/auth.py for the primitives.
"""
import hmac

from fastapi import APIRouter, Request, Response
from fastapi.responses import JSONResponse
from pydantic import BaseModel

from backend.app import auth
from backend.app.config import settings

router = APIRouter()
limiter = auth.LoginRateLimiter()


class LoginRequest(BaseModel):
    username: str
    password: str


@router.get("/status")
async def status():
    return {"enabled": settings.auth_enabled}


@router.post("/login", status_code=204)
async def login(body: LoginRequest, request: Request):
    if not settings.auth_enabled:
        return Response(status_code=204)

    ip = auth.client_ip(request.scope)
    wait = limiter.retry_after(ip)
    if wait:
        return JSONResponse({"detail": "too_many_attempts", "retry_after": wait},
                            status_code=429, headers={"Retry-After": str(wait)})

    user_ok = hmac.compare_digest(body.username.encode("utf-8"),
                                  settings.auth_username.encode("utf-8"))
    password_ok = auth.verify_password(body.password, settings.auth_password_hash)
    if not (user_ok and password_ok):
        limiter.record_failure(ip)
        return JSONResponse({"detail": "invalid_credentials"}, status_code=401)

    limiter.record_success(ip)
    ttl = settings.auth_session_hours * 3600
    token = auth.make_token(settings.auth_username, secret_key=settings.auth_secret_key,
                            password_hash=settings.auth_password_hash, ttl_seconds=ttl)
    response = Response(status_code=204)
    response.set_cookie(auth.COOKIE_NAME, token, max_age=ttl, path="/", httponly=True,
                        samesite="strict", secure=auth.is_https(request.scope))
    return response


@router.post("/logout", status_code=204)
async def logout():
    response = Response(status_code=204)
    response.delete_cookie(auth.COOKIE_NAME, path="/", httponly=True, samesite="strict")
    return response

# backend/app/auth_middleware.py
"""
EmotionLens — gate every request behind the single-user session cookie.

Pure ASGI rather than BaseHTTPMiddleware, because the live analysis runs over
a WebSocket and BaseHTTPMiddleware never sees websocket scopes. Settings are
read per request, so tests (and a restart with a new .env) take effect
without rebuilding the app.
"""
from http.cookies import CookieError, SimpleCookie
from urllib.parse import quote

from backend.app import auth
from backend.app.config import settings

LOGIN_PAGE = "/login.html"

# Everything the login page itself needs, plus health checks.
PUBLIC_PATHS = frozenset({
    LOGIN_PAGE,
    "/css/styles.css",
    "/js/login.js",
    "/js/i18n.js",
    "/js/icons.js",
    "/api/auth/login",
    "/api/auth/status",
    "/api/health",
})
PUBLIC_PREFIXES = ("/i18n/",)

# Custom close code the frontend recognises as "session expired".
WS_UNAUTHORIZED = 4401


def is_public(path: str) -> bool:
    # A dot segment could otherwise ride a public prefix into the rest of
    # the static tree (curl --path-as-is /i18n/../index.html).
    if ".." in path.split("/"):
        return False
    return path in PUBLIC_PATHS or path.startswith(PUBLIC_PREFIXES)


def safe_next(raw: str | None) -> str:
    """Where to go after logging in: local paths only, never another site."""
    if not raw or not raw.startswith("/") or raw.startswith("//") or raw.startswith("/\\"):
        return "/"
    return raw


def _session_token(scope: dict) -> str | None:
    raw = auth.header(scope, b"cookie")
    if not raw:
        return None
    jar = SimpleCookie()
    try:
        jar.load(raw)
    except CookieError:
        return None
    morsel = jar.get(auth.COOKIE_NAME)
    return morsel.value if morsel else None


def has_valid_session(scope: dict) -> bool:
    token = _session_token(scope)
    return bool(token) and auth.token_is_valid(
        token, username=settings.auth_username, secret_key=settings.auth_secret_key,
        password_hash=settings.auth_password_hash)


class AuthMiddleware:
    def __init__(self, app):
        self.app = app

    async def __call__(self, scope, receive, send):
        if scope["type"] not in ("http", "websocket") or not settings.auth_enabled:
            return await self.app(scope, receive, send)

        path = scope.get("path", "")
        if (scope["type"] == "http" and is_public(path)) or has_valid_session(scope):
            return await self.app(scope, receive, send)

        if scope["type"] == "websocket":
            # Accept, then close with our own code: closing before accept
            # reaches the browser as a generic 1006 it can't tell apart from a
            # dropped network.
            await receive()  # websocket.connect
            await send({"type": "websocket.accept"})
            await send({"type": "websocket.close", "code": WS_UNAUTHORIZED})
            return

        if path.startswith("/api/"):
            body = b'{"detail":"not_authenticated"}'
            await send({"type": "http.response.start", "status": 401, "headers": [
                (b"content-type", b"application/json"),
                (b"content-length", str(len(body)).encode("ascii")),
            ]})
            await send({"type": "http.response.body", "body": body})
            return

        query = scope.get("query_string", b"").decode("latin-1")
        target = path + (f"?{query}" if query else "")
        location = f"{LOGIN_PAGE}?next={quote(target, safe='')}"
        await send({"type": "http.response.start", "status": 302, "headers": [
            (b"location", location.encode("latin-1")),
            (b"content-length", b"0"),
        ]})
        await send({"type": "http.response.body", "body": b""})
```

```javascript
/**
 * EmotionLens — login page.
 *
 * Loaded without app.js: before a session exists only i18n.js, icons.js and
 * this file are public (see backend/app/auth_middleware.py PUBLIC_PATHS).
 */
(function () {
    const THEME_KEY = 'emotionlens-theme';

    // Same rule as backend/app/auth_middleware.py safe_next: local paths only.
    function safeNext(raw) {
        if (!raw || raw[0] !== '/' || raw.startsWith('//') || raw.startsWith('/\\')) return '/';
        return raw;
    }

    function applyTheme(theme, button) {
        if (theme === 'dark') {
            document.documentElement.setAttribute('data-theme', 'dark');
        } else {
            document.documentElement.removeAttribute('data-theme');
        }
        button.innerHTML = Icons.render(theme === 'dark' ? 'sun' : 'moon');
    }

    document.addEventListener('DOMContentLoaded', async () => {
        const i18n = new I18nManager('es');
        await i18n.init();
        i18n.updateLangButton();
        const setTitle = () => { document.title = `${i18n.t('login.title')} · EmotionLens`; };
        setTitle();

        const next = safeNext(new URLSearchParams(window.location.search).get('next'));

        // With the login switched off (local development) there is nothing to do here.
        try {
            const status = await fetch('/api/auth/status').then((r) => r.json());
            if (!status.enabled) {
                window.location.replace(next);
                return;
            }
        } catch (err) {
            /* keep the form; submitting will report the problem */
        }

        const form = document.getElementById('login-form');
        const user = document.getElementById('login-username');
        const pass = document.getElementById('login-password');
        const submit = document.getElementById('login-submit');
        const error = document.getElementById('login-error');
        const reveal = document.getElementById('login-reveal');
        const btnTheme = document.getElementById('btn-theme');
        const btnLang = document.getElementById('btn-lang');

        const updateReveal = () => {
            const shown = pass.type === 'text';
            const label = i18n.t(shown ? 'login.hidePassword' : 'login.showPassword');
            reveal.title = label;
            reveal.setAttribute('aria-label', label);
            reveal.setAttribute('aria-pressed', String(shown));
        };

        let theme = 'light';
        try { theme = localStorage.getItem(THEME_KEY) || 'light'; } catch (err) { /* default */ }
        applyTheme(theme, btnTheme);
        btnTheme.addEventListener('click', () => {
            theme = theme === 'dark' ? 'light' : 'dark';
            applyTheme(theme, btnTheme);
            try { localStorage.setItem(THEME_KEY, theme); } catch (err) { /* not persisted */ }
        });

        btnLang.addEventListener('click', async () => {
            await i18n.toggle();
            setTitle();
            updateReveal();
        });

        reveal.addEventListener('click', () => {
            pass.type = pass.type === 'password' ? 'text' : 'password';
            updateReveal();
            pass.focus();
        });
        updateReveal();
        user.focus();

        form.addEventListener('submit', async (event) => {
            event.preventDefault();
            error.textContent = '';
            if (!user.value.trim() || !pass.value) {
                error.textContent = i18n.t('login.invalid');
                return;
            }
            submit.disabled = true;
            submit.textContent = i18n.t('login.submitting');
            try {
                const response = await fetch('/api/auth/login', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ username: user.value.trim(), password: pass.value }),
                });
                if (response.status === 204) {
                    window.location.replace(next);
                    return;
                }
                error.textContent = i18n.t(
                    response.status === 429 ? 'login.locked'
                        : response.status === 401 ? 'login.invalid'
                            : 'login.unavailable');
            } catch (err) {
                error.textContent = i18n.t('login.unavailable');
            }
            pass.value = '';
            pass.focus();
            submit.disabled = false;
            submit.textContent = i18n.t('login.submit');
        });
    });
})();
```

//  SESSION EXPIRY (login enabled on the server)
// ══════════════════════════════════════════
// Any API call answering 401 means the session cookie is gone or expired.
// Installed at load time, before any module makes a request.
const LOGIN_PAGE = '/login.html';

function goToLogin() {
    const here = window.location.pathname + window.location.search + window.location.hash;
    window.location.replace(`${LOGIN_PAGE}?next=${encodeURIComponent(here)}`);
}

const originalFetch = window.fetch.bind(window);
window.fetch = async (...args) => {
    const response = await originalFetch(...args);
    if (response.status === 401) goToLogin();
    return response;
};

```bash

visudo -cf "$SUDOERS_FILE" || { rm -f "$SUDOERS_FILE"; echo "!! Invalid sudoers rule"; exit 1; }
```
